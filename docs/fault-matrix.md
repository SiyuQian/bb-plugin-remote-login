# Remote-login fault evidence

This matrix records assertions inspected in source and tests, not a claim that every listed fault is accepted on a phone or by Oracle. It applies to the protected `oci_cli` and `oci_web` flows and their original native-tool call. Synthetic success proves only the private control path.

Evidence levels:

- **Fixture**: a real component or process is exercised with a substituted dependency, clock, SDK response or service response.
- **Layer integration**: registered server/tool/HTTP/coordinator or host classes are joined; at least one host, browser or provider boundary remains substituted.
- **Composed local browser**: the chain includes actual owned local Chrome; some tests also render the registered frontend at 390px through actual local HTTP. SDK transport and Oracle remain fixtures; Console source attestation is substituted for success cases.
- **Live acceptance**: physical phone control, independently selected real account, actual Oracle response and installed-plugin native-result delivery. **No row has this evidence.**

The composed [CLI success fixture](../tests/cli-flow.test.ts) keeps the installed bootstrap, owned callback, persistence, official diagnostic, SDK signer and match predicates real. Its authorization document is loopback HTTPS and Python `Session.send` returns synthetic service data after checking the actual generated key's RSA signature. The composed [Console fixture](../tests/owned-console-flow-fixture.ts) uses a loopback document/Me service and substituted source attestation. Neither is an Oracle acceptance test.

The [mobile evidence report](mobile-browser-acceptance.md) records actual generated CSS/BB 0.49 base-style fidelity and 390×844 source-frontend evidence. A controlled real inactive-page capture red now has document-barrier green with one capture after callback commit. Same-document vendor behavior is probed separately before callback input. The ordinary post-barrier frontend batch also passed 8/8; historical normal failure was not reproduced, but its exact category/same causality remains unproven. Use revisioned external release evidence for global verdicts. Local fixtures do not establish installed-shell, valid-cloud-token or phone acceptance.

Historical `e0c2641` release evidence is source 1003/1003, compiled entries 8/8 and emitted boundaries 183/183. New controller-competition, tab-visibility and private-origin transport-denial cases each have a focused pass. Their final freeze and full-suite totals are separate revisioned release evidence in `recovery-evidence.json`.
